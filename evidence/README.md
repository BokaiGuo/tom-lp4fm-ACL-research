# Evidence

This directory contains the LP4FM evidence boundary and reader-facing validation summaries.

- `PROJECT_REPORT_zh.md` is the detailed local evidence history.
- `EVIDENCE_LEDGER*` distinguishes verified local evidence from poster-only or secondary claims.
- `confirmed_contribution*`, `results_validation*`, and `writing_rationale_matrix*` are paper-facing summaries.

Design documents and chat exports must not be cited as empirical evidence.

# 写作理由矩阵 中文版

## 叙事原则

论文应按 identification chain 组织，而不是按 Stage 编号汇报。主文中的 reader-facing 对象是 source-indexed answer control、typed conflict topology、source-accessibility cost、additive null、saturation residual 与 checkpoint boundary。内部 stage IDs 只应保留在复现索引与审计文档中。

## 段落功能

| 位置 | 主要功能 | 必须强调 | 必须避免 |
|---|---|---|---|
| Abstract | 用一个闭环概括 source identification、compound prediction 与 checkpoint boundary | fixed worlds、typed competitors、independent confirmation、affine null | hidden-state circuit、universal law |
| Introduction | 解释 accuracy 为什么不能识别 controller | winning answer 不等于 controlling source | 普通 ToM leaderboard opening |
| Task/Methods | 定义 typed source interface 与 same-item crossing | intended source、competitors、margin、leak | 只报告 binary accuracy |
| Behavioral Results | 从 pooled reversal 推进到 topology-conditioned routing | fixed semantics 与 crossed topology | 把 prompt effect 写成自由 paraphrase observation |
| Composition Results | 从 primitive costs 推导 additive null，再预测 held-out compounds | frozen prediction 与 independent worlds | post-hoc min-law 命名 |
| Checkpoint Boundary | 将 Base/Qwen3 failure 写成功能边界 | partial shape、direction failure、affine rejection | instruction tuning causality |
| Discussion | 将贡献定位为 linguistic control interface | measurable、falsifiable、checkpoint-sensitive | human universality 或 broad neural mechanism |

## 主文 claim 顺序

1. accuracy 不识别 controlling source；
2. typed topology 使 source routing 可测；
3. language constructions 调节 source access；
4. primitive costs 对 unseen compounds 产生 falsifiable prediction；
5. independent worlds 确认 subadditivity；
6. new checkpoints 限定 law 并拒绝 affine compression。

## 写作边界

必须使用“behavioral source routing”“checkpoint-sensitive composition”“saturating class”等措辞。只有在新实验区分 operator 后，才能进一步命名 weakest-link 或 capacity law；只有 longitudinal 与 controlled training 通过后，才能讨论 training-time causality。

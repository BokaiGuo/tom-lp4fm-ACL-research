# 已确认贡献 中文版

## 母对象

论文研究 source-indexed answer control：当 latent world 固定，而 linguistic access 与 typed competitors 改变时，哪个 described source 控制模型答案。

## 核心张力

false-belief accuracy 只能识别 winning answer，不能识别使其获胜的 controller。pooled prompt effects 因而不可识别，并可能跨 item pools 反转。

## 已确认贡献

1. 一个 typed conflict intervention，使固定语义下的 source control 在行为层面可识别。
2. 一个 source-accessibility cost，其 additive null 能预测 unseen compound constructions。
3. 在 Qwen2.5-7B-Instruct 上独立确认 subadditive composition。
4. 一个 affine-gain invariance proposition，以及 frozen checkpoint comparisons，证明 composition boundary 是 functional difference，而不是 scalar confidence compression。

## 证据主链

pooled effects 失败，typed topology 解决不稳定性；reportative reversal 将解释收敛到 source access；primitive restrictions 预测 held-out compounds；新 latent worlds 确认 subadditivity；新 checkpoints 限定定律范围并拒绝 affine scaling。

## Claim Boundary

证据支持 checkpoint-sensitive behavioral theory of linguistic source routing，但不建立 unique neural operator、hidden-state belief circuit、instruction tuning causal effect、broad model-family law 或 human psycholinguistic universal。

## 对 LP4FM 的意义

语言表示不仅是内容，也构成控制接口。discourse form、reference、voice、embedding locality 与 source attribution 会调节哪个 described state 到达答案。该接口的组合行为可测量、可证伪并具有 checkpoint sensitivity。

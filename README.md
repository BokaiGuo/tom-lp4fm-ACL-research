# ToM / LP4FM Research Documents

Private document repository for the Theory-of-Mind / LP4FM research program.

## Contents

- `manuscript/lp4fm2026/`: current LP4FM manuscript source, figures, tables, and rendered PDF.
- `proposals/`: five independent oral branches plus the combined source-access algebra proposal.
- `research/`: stage evolution and research-branch analysis.
- `theory/`: source-accessibility saturation theory.
- `evidence/`: contribution, validation, claim-boundary, and project-report documents.

## Scope

This repository intentionally contains manuscript and research-planning documents only. It excludes model weights, prompts with operational secrets, run logs, large experiment outputs, caches, and local environment files.

## Current manuscript position

The LP4FM manuscript is the bounded empirical foundation: it identifies typed source routing, confirms a subadditive composition class in the reference checkpoint, and defines checkpoint-sensitive behavioral limits. The combined oral branch asks whether training changes the underlying source-access composition operator.

# 构造，而非蕴涵
### 类型论与形式语义学视角下 LLM 表示设计的统一研究方案

**版本**：整合版 v1.0（2026 年 9 月）
**子方案**：L1《Schemas Are Types》、L2《Accessibility, Not Attention》、L3《Rules or Recall?》。本文件是三者的总纲，负责统一框架、执行顺序、门控决策与资源规划；实验细节以子方案为准，本文件在必要处给出摘要，并在整合中对子方案做了若干修正（见 §2.3、§2.4、§7.3）。

---

## 0. 摘要

"表示设计会影响 LLM 表现"已经是共识，但现有工作停留在现象层。它们无法定义"两个表示对应同一任务"，无法在运行模型之前预测哪种表示更好，也无法解释收益从何而来。

本方案提出一个统一论点：

> **LLM 从表示中获得的收益，取决于它所需要的东西在表示中是被构造出来的，还是只是被蕴涵的。** 具体分三个层面：约束是由类型承担还是由推理承担（L1），实体是作为见证项可达还是仅仅被断言存在（L2），概念是由和谐的规则确定还是需要模型回落到先验去补全（L3）。三者的共同效果是让模型需要做的推理成为一个规范的、焦点选择尽可能少的证明。

这一论点有三个方法论支柱：

1. **证明相关的等价判据**：比较两个表示时，不仅要求可证性相同，还要求证明项（见证）层面可以互相翻译。这把"信息量相同"从直觉判断变为可机械验证的事实，并暴露出"仅经典等价"这一此前被忽略的混淆源。
2. **先验可计算的结构度量**：静态化比例 \(\sigma\)、焦点复杂度 \(\kappa\)、可及性 \(\mathrm{Acc}\) 与抽取深度 \(\lambda\)、和谐状态 \(h\) 与保守性 \(\mathrm{Cons}\)。它们全部可以在不运行模型的情况下算出。
3. **锋刃对照**：每条线都有一个"表面属性全部匹配，只有结构变量不同"的关键条件。效应若在这些条件上出现，就不能被长度、形式外观、否定词或推理步数等表面解释所消解。

执行上，三条线共用一套形式工具链与一组模型，按依赖关系分五个阶段推进，约 44 周。L3 的焦点复杂度效度检验与 L2 的等价性分类器排在前面，因为 L1 的度量与材料依赖它们。

## 1. 研究问题与三条线的定位

### 1.1 总问题

在语义等价的前提下，表示的哪些结构属性决定了 LLM 的表现？这些属性能否在运行模型之前被计算和用于预测？

### 1.2 三条线

| | L1 约束搬迁 | L2 见证可达 | L3 规则和谐 |
|---|---|---|---|
| 子问题 | 约束落在类型层还是命题层，影响多大 | 语篇中的实体何时能被后文使用 | 语境规则何时能取代训练先验 |
| 理论来源 | 类型论、refinement/dependent types | DRT、动态语义、依存类型语义（DTS） | 证明论语义、和谐性、焦点化 |
| 先验度量 | \(\sigma\)、\(\kappa\) | \(\mathrm{Acc}\)、\(\lambda\) | \(h\)、\(\mathrm{Cons}\)、\(\kappa\) |
| 锋刃对照 | S2 伪形式化：外观形式化而 \(\sigma\)、\(\kappa\) 不变 | C3/C4b：实体存在被蕴涵但见证不可达 | D 组：推理步数相同而焦点复杂度不同 |
| 典型失败 | 违反未被类型化的约束 | 指称泄漏、预设的全局迁就（幻觉） | 先验入侵、无根消去 |
| 机制层问题 | 双可解释表示下内部表征是否不变（\(\tilde{\Delta}\)） | 是否存在跨算子统一的可及性表征 | 规则依从与先验依从是否有不同的计算签名 |

### 1.3 三条线之间的依赖

```
          ┌──────────────────────────────┐
          │  共享形式工具链（阶段 0）       │
          └──────────────┬───────────────┘
             ┌───────────┴────────────┐
             ▼                        ▼
   L3：κ 效度检验（门 1）      等价性分类器（门 0）
             │                        │
             │                  L1 材料审计（门 2）
             │                        │
             └───────────┬────────────┘
                         ▼
                L1 主实验（门 3 之后）
                         │
    L2 主实验 ───────────┤（并行，不依赖 L1）
                         ▼
               跨线分析与机制比较（阶段 4）
```

依赖关系的理由：

- **L1 → L3**：L1 主假设中的 \(f(\kappa)\) 项从未被独立检验。若焦点复杂度不是正确的难度度量，L1 的因子设计与预测模型都要改。
- **L1 → L2**：L1 的五档表示如果有两档只在经典意义下等价，其性能差异可能来自见证可达性，而被错误地归因于 \(\sigma\)。
- **L2 与 L3 相互独立**：两者的行为实验可以并行，只在阶段 4 做跨线相关分析。

## 2. 统一形式框架

### 2.1 任务、表示与语义源

所有任务在一个受限的依存类型论片段中表述。一个任务是一个判断：

\[
T \;=\; (\Gamma \vdash A)
\]

一个表示 \(\rho\) 是从任务到某个表层形式的渲染，其语义通过翻译回到类型论片段来确定：

\[
\rho : T \longmapsto \big(\Gamma_\rho \vdash_{\mathcal{T}_\rho} A_\rho\big)
\]

所有刺激材料都由一个**语义源**（任务 DSL 中的类型项）生成，再由渲染器变成自然语言、伪代码或形式记法。这样做的关键好处是：等价性在语义源层面机械验证，渲染器的忠实性单独检验（§4.3），两件事不混在一起。

### 2.2 片段的选择

片段需要同时覆盖三条线的需求：

- **L1**：refinement 类型、量纲或 phantom 类型、typestate、线性资源；
- **L2**：\(\Sigma\) 类型（存在与见证）、\(\Pi\) 类型（条件与全称）、否定 \(A \to \bot\)、析取 \(A + B\)；
- **L3**：定义式规则（合取、析取、存在体），以及可逆与不可逆规则的极性标注。

实现上，形式核心使用 Lean 4 做等价验证与证明项检查，证明搜索与度量计算用自写的受限证明器完成（Lean 负责"对不对"，自写工具负责"难不难"），生成与渲染用 Python。

### 2.3 等价判据（整合后的修订版）

子方案 L1 原有三级等价判据。整合 L2 的发现后，修订为四级：

| 级别 | 定义 | 验证方式 | 用途 |
|---|---|---|---|
| **A⁺ 证明相关** | 存在双向翻译，保持可证性，且在证明项层面互为拟逆 | Lean 中关闭经典公理构造翻译与往返证明 | 所有锋刃对照与主结论 |
| **A 经典** | 双向翻译保持可证性，但往返需要经典公理 | Lean 中允许经典公理 | 作为 L2 与跨线分析的操纵变量 |
| **B 外延** | 在完整输入分布上诱导同一输入输出函数 | 穷举或大样本测试 | 半合成任务 |
| **C 观察** | 专家判断指称同一任务，信息内容匹配 | 人工标注 | 真实任务附录 |

这次修订把一个潜在混淆变成了一个自变量：凡是只达到 A 级而未达到 A⁺ 级的表示对，不再被当作"等价"混入主分析，而是单独成组，用来检验跨线假设 X1（§3.3）。

### 2.4 预测量总表（整合后的修订版）

| 度量 | 所属线 | 定义摘要 | 计算方式 |
|---|---|---|---|
| \(\sigma(\rho)\) | L1 | 相对基线表示，被语法或类型层消除的非法状态比例 | 有界枚举 + 类型检查器 + 语义 oracle |
| \(\kappa_0\) | L1、L3 | 最短焦点化证明中的焦点阶段数 | 焦点化证明器 |
| \(\kappa_1\) | L1、L3 | 有效选择点数：焦点阶段中存在两个以上可应用候选的次数 | 焦点化证明器 + 候选枚举 |
| \(\kappa_2\) | L1、L3 | 焦点化搜索树规模的对数（到首个成功证明为止） | 有界搜索 |
| \(n_{\text{step}}\) | 对照 | 证明总步数 | 证明器 |
| \(\mathrm{Acc}, \lambda\) | L2 | 见证能否经由作用域内变量与 \(\Sigma\) 消去取出；所需最少消去步数 | DTS 构造器 + 受限证明搜索 |
| \(h\) | L3 | 给定消去规则相对规范消去规则的状态：和谐、过强、过弱、混合 | 反演生成 + 蕴涵比较 |
| \(\mathrm{Cons}\) | L3 | 新规则是否为旧词汇理论的保守扩展 | Datalog 或一阶证明器 |
| \(\mathrm{Eq}\) | 全部 | 表示对的等价级别（A⁺/A/B/C） | Lean + 测试 |

**关于 \(\kappa\) 的修订。** L1 把 \(\kappa\) 定义为焦点阶段数，L3 实际使用的是选择点。两者并不相同：一个焦点阶段可能只有唯一可用的候选，此时并不存在真实的选择。整合方案把三个变体 \(\kappa_0, \kappa_1, \kappa_2\) 同时计算，由 L3 的 D 组实验决定哪一个最能预测 LLM 错误（门 1），胜出者记为 \(\kappa^{*}\)，供 L1 使用。

## 3. 假设体系

为控制多重比较，假设分为三层。只有验证性假设进入预注册的主检验，并做 Holm 校正；其余明确标注为次级或探索性。

### 3.1 验证性假设（7 条）

| 编号 | 来源 | 假设 | 锋刃条件 |
|---|---|---|---|
| **V1** | L3 | 推理步数匹配时，错误率随 \(\kappa^{*}\) 上升；\(\kappa^{*}\) 的预测力优于 \(n_{\text{step}}\) | D 组 |
| **V2** | L3 | 焦点化脚手架相对反焦点化对照的收益随 \(\kappa^{*}\) 增大 | D 组高 \(\kappa\) 格 |
| **V3** | L2 | 在排除否定词与自然度效应（C8、C9 无下降）之后，实体存在被蕴涵而见证不可达的格子上，模型的回指许可偏离真值条件模型的预测。**双侧检验**：\(\mathrm{SA} > 0.5\) 支持动态模型，\(\mathrm{SA} < 0.5\) 或真值条件模型胜出同样作为主结论报告 | C3、C4b |
| **V4** | L2 | 下游泄漏率与全局迁就率的算子排序由 \(\mathrm{Acc}\) 与 \(\lambda\) 预测 | 否定与条件引入的实体 |
| **V5** | L1 | 伪形式化表示（S2）相对自然语言命题表示（S1）无显著增益；\(\sigma\) 上升时错误率单调下降 | S2 |
| **V6** | L1 | 单条不变式从命题层搬到类型层的效应，不小于从隐含层搬到命题层的效应 | (I, P, T) 三元组 |
| **V7** | 跨线 | 在同一模型上，仅经典等价（A 级）表示对的内部表征差距 \(\tilde{\Delta}\) 显著大于证明相关等价（A⁺ 级）表示对 | A 与 A⁺ 表示对 |

### 3.2 次级假设

- **L1**：\((\sigma, \kappa^{*})\) 对留出任务族的表示排序预测达到 Spearman > 0.6；\(\sigma\) 效应在反事实本体下保留一半以上；\(\sigma\) 效应在长 CoT 下减弱。
- **L2**：规模越大，情态从属与浴室句上越接近人类常模；元语言判断与概率测量分离。
- **L3**：先验冲突下和谐规则的依从度最高；反演差距大于零；模型执行无先验冲突的 tonk 规则而很少指出规则缺陷；CoT 错误定位比大于一。

### 3.3 跨线与探索性假设

- **X1**（即 V7 的行为版）：仅经典等价表示对上的准确率差距大于证明相关等价表示对。
- **X2**：L2 的 C3 格回指失败率与 L3 不和谐条件（A5）的推理失败率在模型之间正相关。
- **X3**：L1 中提高 \(\sigma\) 会降低 \(\kappa^{*}\)，即类型化约束把选择点变成无需选择的步骤。这为 L1 中 \(\sigma\) 与 \(\kappa\) 的共线性提供理论解释。
- **X4**：模型层面的表示敏感性（L1 的 \(\sigma\) 斜率）、结构对齐度（L2 的 \(\mathrm{SA}\)）与语义模式指数（L3 的 \(\mathrm{SMI}\)）之间存在一个共同因子。
- **X5**（机制）：L2 的可及性方向、L3 的规则归因签名、L1 的不变性差距，在同一模型的相同层段中出现。

**关于统计功效的提醒。** X2、X4 以及 L1 的 H5 都是**模型层面**的相关分析，而模型面板只有约 15 个模型。这类检验功效很低，因此一律列为探索性。Olmo 的训练中间检查点可以增加数据点，但它们彼此不独立，需要用分层模型处理，不能直接当作独立样本计数。

## 4. 共享基础设施

### 4.1 形式工具链（ctorkit）

| 模块 | 功能 | 服务对象 |
|---|---|---|
| `core` | 受限依存类型片段的语法、类型检查 | 全部 |
| `dsl` | L1 五个任务族、L2 语篇文法、L3 规则模板的语义源生成 | 全部 |
| `equiv` | 在 Lean 4 中构造翻译并判定 A⁺/A 级；测试判定 B 级 | 全部，门 0 与门 2 |
| `focus` | LJF 风格的焦点化证明器，输出 \(\kappa_0, \kappa_1, \kappa_2, n_{\text{step}}\) 与选择点列表 | L1、L3 |
| `sigma` | 非法状态枚举与重要性采样估计 | L1 |
| `dts` | DTS 语义构造，计算 \(\mathrm{Acc}, \lambda\) | L2 |
| `harmony` | 规范消去生成、和谐状态判定、保守性检验 | L3 |
| `render` | 多档表示渲染（自然语言、伪代码、形式记法、无意义词替换） | 全部 |
| `parse` | CoT 到规则应用序列的约束解析与形式检查 | L3，L1 的 CoT 分析 |

### 4.2 模型面板

三条线使用**同一组模型与同一套解码设置**，否则跨线分析无法进行。具体版本以项目启动时的最新发布为准。

| 类别 | 构成 | 用途 |
|---|---|---|
| 规模序列 A | 同一开放权重家族的 5 个规模档（约 0.5B 到 70B 级） | 行为、规模趋势、机制 |
| 规模序列 B | 另一开放权重家族的 3–4 个规模档 | 家族间复现 |
| 训练轨迹 | Olmo 系列的基座模型及 6–8 个中间检查点 | 敏感性何时出现，语料频率查询 |
| 基座与指令对 | 至少 3 对同规模的基座与指令版本 | 指令微调的影响 |
| 推理型模型 | 2 个带长内部推理的模型（开放权重优先） | 推理算力与表示设计的替代关系 |
| 前沿闭源模型 | 2–3 个，仅行为层，仅在核心子集上运行 | 外部效度 |

**解码条件**：直接回答（温度 0）、自由 CoT（温度 0，另在子集上用温度 0.7 采样 5 次估计稳定性）、线路特定的脚手架条件。

### 4.3 测量协议

- **基座模型**使用对数概率类度量；**指令模型**同时报告概率（若可得）与生成式判断，二者的一致性作为一项结果报告。
- **渲染器忠实性检验**：每个渲染后的表示抽样由两名标注者回译到语义源，不一致的模板整体淘汰。
- **激活缓存**：只缓存预注册的层段与 token 位置（提示末 token、关键指称位置、回指位置、答案起始位置），以控制存储规模。
- **SAE**：优先使用面板模型已公开的稀疏自编码器；对没有公开 SAE 的模型只用 CKA 与线性探针，不自行训练大规模 SAE。

### 4.4 人类数据

L2 的人类常模为必需，L3 的心智模型错觉题人类基线为可选。两者合并为**一次伦理审查申请**，于阶段 0 提交。

## 7. 统计与预注册

### 7.1 预注册

- 平台：OSF。
- **分两次注册**：第一次在阶段 0 结束时，注册 V1–V6 与 L3、L2 的分析计划；第二次在门 1 与门 2 之后、L1 主实验之前，注册 \(\kappa^{*}\) 的选择结果、L1 的最终材料与 V7 的分析计划。第二次注册必须早于任何 L1 主实验数据的产生。
- L1 实验 4 与 L2 的 prompt 结构规则实验均为"先注册预测，后运行"，预测文件带时间戳公开。

### 7.2 主要分析模型

- 行为数据：广义线性混合模型，项目与模型为交叉随机效应，表层措辞变体为嵌套随机效应。
- 理论模型比较（L2 的四模型、L3 的三模式、\(\kappa\) 变体比较）：留一交叉验证的 ELPD；报告差值及其标准误，不用单一阈值做二元裁决。
- 表征相似度：配对 bootstrap 置信区间；\(\tilde{\Delta}\) 必须带噪声地板与任务天花板两个锚点。
- 效应量优先于 p 值报告。

### 7.3 多重比较

- V1–V7 共 7 条，做 Holm 校正，族错误率 0.05。
- 次级假设在各自子方案内做 Holm 校正，结论表述为"次级证据"。
- 探索性分析不做显著性裁决，只报告估计与区间。

### 7.4 样本量

子方案中给出的项目数是计划上限。实际样本量在各线试点后用模拟法确定：以试点估计的效应量与随机效应方差为参数，模拟达到 80% 功效所需的最少项目数。若所需项目数超出材料生成能力，优先保证锋刃条件的样本量，削减非关键格。

- **复现**：开放代码、材料生成种子、模型版本号、解码参数与分析脚本。

| L3 | D 组 | 推理步数、规则条数、token 数 | 焦点选择点数量 | "推理链越长越难" |
| L3 | 焦点化对反焦点化脚手架 | 格式、长度 | 可逆步骤与选择步骤的顺序 | "提示结构越清楚越好" |
| 跨线 | A⁺ 对 A 级表示对 | 经典可证性 | 证明项层面的可翻译性 | "等价就是等价，表示差异只是噪声" |

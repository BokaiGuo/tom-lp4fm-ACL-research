# Archive

This directory preserves research provenance for collaborator discussion.

- `chat-exports/`: original conversation exports, unchanged.
- `synthesis-notes/`: supplied integrative analyses, renamed for discoverability but not edited.
- `legacy-plans/`: roadmaps superseded by `MASTER_RESEARCH_PLAN.md`.

Archived materials are not evidence, not current instructions, and not authoritative when they conflict with the frozen study design or evidence ledgers.

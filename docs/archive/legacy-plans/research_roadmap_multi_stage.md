## 执行摘要

本路线图将原始的"冲击最佳论文"构想切割为 **6 个独立但相互关联的研究阶段**，每个阶段可产出独立论文，同时共同构建一个关于**关系识别、控制与语言经验**的统一理论框架。

**核心科学问题**：
> 上下文证据如何使模型识别关系？被识别的关系何时真正获得行为控制权？语言经验如何塑造这一过程？

**关键创新**：
1. 将 "relation identification" 与 "relation control" 作为两个可独立测量的计算阶段
2. 引入可先验计算的结构度量（Relation Information $I_R$, Relation Control Effect $RCE$）
3. 从观察性跨语言比较推进到因果性语言经验操纵
4. 建立人工神经系统与人类认知的结构对应

## Paper B: From Evidence to Control
### 关系信息如何使规则被识别并获得控制权

**状态**: 当前最高优先级，对应原 canonical plan  
**预计时间**: 20 周（从当前开始）  
**目标会议**: ACL/EMNLP 2027 或 ICLR 2027

### 核心贡献

**三个主实验构成完整链条**：

```
Experiment 1: Information, not example count
   问题：什么证据使关系可识别？
   核心发现：1 diagnostic > 16 consensus demos
   理论对象：Relation Information I_R(D)

Experiment 2: Identification × Prior Pressure  
   问题：识别后的关系何时获得控制权？
   核心发现：identification ≠ control (dissociation)
   理论对象：Relation Control Effect (RCE)

Experiment 3: Functional partner adaptation
   问题：控制效应是否影响真实行动？
   核心发现：relation-policy swap → behavior flip
   理论对象：RCE in action
```
